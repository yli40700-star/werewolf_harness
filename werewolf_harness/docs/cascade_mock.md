# 级联配对实验：mock-flaky:0.3（便宜） / mock-strong（强）

命令：`python -m werewolf_harness.scripts.paired_cascade --seeds 2001-2020 --cheap mock-flaky:0.3 --strong mock-strong --arms strong,cheap,cascade,cascade-on-fail --record --jobs 4 --out runs/cascade_mock/`（容器内 36 秒，80 局）。机制见 docs/adr/0014-model-cascade.md。

种子 2001–2020（20 个）（每个种子 = 同一副牌，每个实验臂都打一遍），板子 8p，并行 8，级联方式 both。比例给按局 bootstrap 区间；配对差 = 实验臂 − strong，按种子成对重抽样（B=2000）。
价格（USD / 百万 token，输入/输出）：mock-strong 3/15；mock-flaky:0.3 1/5。来源见 scripts/paired_cascade.py 的 PRICES；cache 读写按普通输入计价，绝对值偏高，两臂之比不受影响。

> **这是 mock 跑出来的数**：便宜档是 FlakyMockClient（按种子确定地犯小模型的错），强档是普通 MockClient。它们证明流水线和统计是通的，不代表任何真实模型的质量。
