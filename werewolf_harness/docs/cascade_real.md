# 模型级联：真实模型配对实验（ADR 0014）

2026-10-15，本机 `claude -p`（订阅额度）。便宜模型 `claude-cli:haiku` 实际是 `claude-haiku-5-5`，强模型 `claude-cli:sonnet` 实际是 `claude-sonnet-5-5`（模型名取自录像里 CLI 返回的 `modelUsage`）。

- 种子：2001–2010。每个种子是同一副牌，三个实验臂各打一遍：
  - strong：全程强模型；
  - cheap：全程便宜模型；
  - cascade：级联，`both` 方式。
- 板子：8 人局，并行 8，守卫 L1+L2+L3，引擎 v2。
- 一共 30 局，全部录像（`--record`），用时 1 小时 48 分钟。

完整报告：`docs/cascade_real_report.md`；数据：`docs/cascade_real.json`。

```
CLAUDE_CLI_CONCURRENCY=8 python -m werewolf_harness.scripts.paired_cascade --seeds 2001-2010 \
  --cheap claude-cli:haiku --strong claude-cli:sonnet --arms strong,cheap,cascade --cascade-mode both \
  --variant 8p --parallel 8 --record --out runs/cascade/ \
  --price claude-cli:haiku=0.1,0.5 --price claude-cli:sonnet=2,10
```

## 价格

2026-10-15 在 Anthropic 官方定价页（platform.claude.com/docs/en/about-claude/pricing）核实，单位是每百万 token 的输入 / 输出价格：

| 模型 | 价格 |
|---|---|
| Haiku 5.5 | $0.10 / $0.50（prompt 不超过 100K token，本实验的调用都在这一档） |
| Sonnet 5.5 | $2 / $10 |

两者相差 20 倍。早先文档里写的 $1/$5、$3/$15 是上一代 Haiku 4.5 和 Sonnet 4.6 的价格，两者只差 3 倍。

脚本把 cache 读写一律按普通输入计价，所以每局的美元数是**上限**；两臂之比不受这一点影响。

## 结果

| 指标 | strong | cheap | cascade |
|---|---|---|---|
| 成本 USD/局（上限） | 1.112 [1.022, 1.208] | 0.087 [0.079, 0.095] | 0.378 [0.333, 0.427] |
| **成本之比（对 strong，配对）** | 1 | **0.08** [0.07, 0.09] | **0.34** [0.30, 0.40] |
| CLI token/局 | 456,219 | 541,054 | 495,711 |
| 合法动作率（回合） | 99.6% (546/548) | 99.8% (591/592) | 99.6% (543/545) |
| 一次过率（回合内没被拦过） | 94.5% | 98.3% | 92.3% |
| 兜底率 | 0/548 | 0/592 | 2/545 |
| 守卫拦截率（回合） | 1.6% | 0.2% | 0.7% |
| 升级到强模型的回合 | — | — | 44.8% (244/545) |
| 整局时长 s | 192.5 | 220.6 | 232.6 |
| 好人胜率 | 7/10 | 5/10 | 7/10 |

下表是配对差（实验臂 − strong，按种子成对 bootstrap，B=2000，n=10）：

| 指标 | cheap | cascade |
|---|---|---|
| 合法动作率 | +0.2 点 [−0.4, +0.7] | −0.0 点 [−0.5, +0.5] |
| 一次过率 | **+3.9 点 [+0.7, +7.2]** | −2.2 点 [−4.6, +0.3] |
| 兜底率 | +0.0 点 | +0.4 点 [+0.0, +0.9] |
| 守卫拦截率 | −1.5 点 [−3.5, +0.0] | −0.9 点 [−3.2, +0.7] |
| 整局时长 s | +28 [−35, +86] | +40 [−19, +94] |
| 好人胜率 | −20 点 [−60, +30] | +0 点 [−30, +30] |

**非劣效**：容差是合法动作率不比 strong 低 2 个百分点。cheap 和 cascade 都成立，区间下界分别是 −0.4 点和 −0.5 点。

## 读数

- **级联的成本是强模型的 0.34 倍，合法率不差。** 但钱几乎全花在“关键回合”上：244 次升级里，238 次是 `decisive`（投票、夜间行动按策略直接交给强模型），因为出错而升级的只有 6 次（4 次未查证引用、2 次 schema）。如果只按出错升级（`on-fail`），成本会接近 cheap 臂。
- **这一代便宜模型在“动作合法”这件事上不输强模型。** cheap 的一次过率反而高 3.9 个点，区间不含 0；sonnet 更常被守卫拦下（1.6% 对 0.2%）。所以级联“失败就升级”的那一半，在这对模型上几乎没有触发的机会。
- **价格比例决定级联值不值。** 同样的 token 量，换成上一代 3 倍价差（$1/$5 对 $3/$15）重算：cascade 是 0.64 倍 [0.57, 0.75]，cheap 是 0.52 倍 [0.44, 0.61]。之前模拟实验（`docs/cascade_mock.md`）用的也是 3 倍价差，得到 0.56–0.73 倍，与这次的 0.64 一致。
- **胜率只能看方向。** 每臂 10 局，区间宽到 ±30 个点以上。“关键回合交给强模型是否下得更好”，这个样本量回答不了。

## 局限

- 只有 10 个种子，只有一对模型、一种板子。
- `claude -p` 的 token 包含 cache 读写，美元数是上限，见上文“价格”。
- 整局时长和单次调用延迟受本机 CLI 并发（8）和订阅额度排队影响，只能做同批次内的相对比较。
